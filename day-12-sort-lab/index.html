How it works

Follow the pseudocode

    Highlighted pseudocode is a teaching sketch, not every JavaScript line. Active bars can indicate comparison, reading or writing; read the caption for the exact operation.

    Read the motion, not just the result.

    Try insertion sort on nearly sorted data; compare quick sort on random and already sorted data. Counting and radix use keys and digits rather than pairwise placement comparisons. Their auxiliary work still counts.

    n = item count, k = key range, d = digit count, b = radix base (10). Complexity describes the algorithm—not the animation snapshots, DOM drawing, or simulated speed. Stability means preserving the order of equal-key records; identical bars cannot demonstrate that property by themselves.
