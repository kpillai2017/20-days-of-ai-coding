# 20 Days of AI Coding — two projects down!

🚀 I've started **20 Days of AI Coding**: one small project a day, built with AI assistance.

The first two are ready:

- 🟩 **Pixel Life** — Conway's Game of Life in HTML, CSS and JavaScript.
- 🧱 **Breakout** — a paddle-and-bricks game in Python and pygame.

The aim isn't just to get working code — it's to understand it. Each project includes beginner-friendly comments, setup instructions, a code walkthrough, references and tests.

Two down, eighteen to go!
