# Enigma programming references

## 3D programming references and dependency rights

- [PyOpenGL documentation](https://pyopengl.sourceforge.net/documentation/):
  Python bindings for OpenGL/GLU, separately installed as PyOpenGL 3.1.10.
- [PyOpenGL licence](https://github.com/mcfletch/pyopengl/blob/master/license.txt):
  BSD-style licence; package copyright/licence remain with its authors.
- [Pygame display/OpenGL attributes](https://www.pygame.org/docs/ref/display.html):
  compatibility-context creation and double buffering.
- [OpenGL fixed-function pipeline](https://wikis.khronos.org/opengl/Fixed_Function_Pipeline):
  historical API context and modern alternatives. Used here for teaching clarity,
  not as a recommendation for a new high-performance renderer.

3D geometry, key/rotor labels and lighting are original procedural artwork. No
third-party models, scans, textures, logos or museum imagery are bundled.
